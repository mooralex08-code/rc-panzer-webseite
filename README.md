# FORMORA – Produktansicht + Bewertungen

Neu:
- Produkt im Shop anklicken -> große Einzelansicht als Overlay
- X oben rechts -> sofort zurück zum Shop
- größere Produktdarstellung, Kategorie, Beschreibung, Preis und Zusatzinfos
- Warenkorb-Button auch in der Einzelansicht
- Neuheiten-Bereich vollständig entfernt
- Bewertungen ohne Stern im Menü/Seitentitel
- keine erfundenen Demo-Bewertungen mehr
- Besucher können Name, 1–5 Sterne und Text absenden
- Bewertungen erscheinen direkt auf der Bewertungsseite
- Admin kann gespeicherte Bewertungen löschen

WICHTIG:
Die Bewertungsfunktion speichert aktuell im Browser (localStorage). Auf einer reinen GitHub-Pages-Seite sind Bewertungen deshalb NICHT automatisch für alle Besucher gemeinsam sichtbar und können nicht geräteübergreifend administriert werden. Für echte öffentliche Bewertungen braucht FORMORA eine Datenbank / ein Backend (z.B. Supabase/Firebase/eigener Server).
